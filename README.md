# Pomodoro‑timer

En enkel Pomodoro‑timer laget i HTML, CSS og JavaScript.

## Funksjoner
- 25 minutter arbeid / 5 minutter pause
- Automatisk bytte mellom arbeid og pause
- Visuell feedback via bakgrunnsfarge
- Start / Pause / Reset

## Formål
Prosjektet er laget for å lære:
- grunnleggende JavaScript
- hvordan UI reagerer på tilstand (state)
- bruk av GitHub og Copilot i praksis

- Lyd/varsling ved bytte
- Bakgrunnsbilder (stemning)
